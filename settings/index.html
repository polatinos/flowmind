FlowMind

Chat in gewone taal met een AI die je Homey uitleest, apparaten aanstuurt en flows bouwt.
Instellingen (AI-provider & API-keys)
⭐ Makkelijkste optie: OpenCode Zen (gratis)
Werkt direct, zonder key: provider OpenCode Zen staat al geselecteerd en gebruikt het gratis model Big Pickle. Optioneel kun je een eigen key instellen (opencode.ai/auth), bijv. voor hogere limieten.
Keys worden versleuteld opgeslagen op je Homey en nooit teruggestuurd naar deze pagina. Laat een veld leeg om de bestaande key te behouden. De Base URL geldt voor de provider "OpenAI-compatibel" (Ollama/Groq/lokaal, of Gemini via Google's OpenAI-endpoint).
Alleen inschakelen als je begrijpt wat dit doet: de AI kan dan code uitvoeren met toegang tot je Homey. Standaard uit.

Chat in plain language with an AI that reads your Homey, controls devices and builds flows.
Settings (AI provider & API keys)
⭐ Easiest option: OpenCode Zen (free)
Works out of the box, no key needed: the provider OpenCode Zen is selected by default and uses the free Big Pickle model. Optionally set your own key (opencode.ai/auth), e.g. for higher limits.
Keys are stored encrypted on your Homey and never sent back to this page. Leave a field empty to keep the existing key. The Base URL applies to the "OpenAI-compatible" provider (Ollama/Groq/local, or Gemini via Google's OpenAI endpoint).
Only enable this if you understand what it does: the AI can then execute code with access to your Homey. Off by default.
🔑 Homey API key (needed to create flows)
Without this key the AI can read your system and control devices, but not create or edit flows — Homey does not give apps that permission. Create a key via my.homey.app → Settings → System → API keys and paste it here. It never leaves your Homey.
🖥 Web terminal (desktop)
Full-screen terminal for desktop browsers, served by the app on your own network. Only reachable at home (LAN) and protected with an access token; API keys are never exposed on it.
Memory (what the AI remembers)
The AI saves lasting facts and preferences here (e.g. "the nursery must stay at 19°C"). They are included in every conversation. You can also just tell the AI to remember or forget something.

# HomeyAI

## Claude Code

Deze repository is uitgerust met [Claude Code](https://claude.com/claude-code)
via GitHub Actions.

### Wat kun je ermee?

- **`@claude` mentions** — noem `@claude` in een issue of pull request comment
  en Claude Code voert de gevraagde taak uit (code schrijven, bugs fixen,
  vragen beantwoorden).
- **Automatische PR reviews** — elke pull request krijgt automatisch een
  code review van Claude.

### Setup (eenmalig)

1. Installeer de Claude GitHub App: https://github.com/apps/claude
2. Voeg het secret `ANTHROPIC_API_KEY` toe onder
   **Settings → Secrets and variables → Actions**.

Zie [`CLAUDE.md`](./CLAUDE.md) voor projectrichtlijnen.
